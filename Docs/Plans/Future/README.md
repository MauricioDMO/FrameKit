# FrameKit Roadmap

This directory contains the forward-looking product and engineering plans for FrameKit.

The existing `Docs/Plans/framekit-alpha/` directory should remain unchanged as a historical engineering record. These roadmap plans describe future work and may be edited, split, reordered, or removed as the product evolves.

## Planning rules

Each plan should define:

1. The problem being solved.
2. The functional objective.
3. The main design decisions.
4. What is included.
5. What is explicitly out of scope.
6. Dependencies on other plans.
7. Completion criteria.

A feature belongs in the roadmap only when it improves one of these workflows:

- Create a FrameKit project.
- Create a template.
- Organize templates.
- Edit the values exposed by a template.
- Save or share an edit.
- Export a reliable result.
- Extend FrameKit without unnecessarily increasing the core.

Tests are intentionally summarized in `16-testing-summary.md`. The other plans should contain functional completion criteria rather than full testing strategies.
