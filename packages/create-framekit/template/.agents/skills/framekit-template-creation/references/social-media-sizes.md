# Social Media Template Sizes

Use these as practical master formats, not as a complete list of platform limits.

## Master formats

| Format | Size | Use |
| --- | --- | --- |
| Square | `1080 x 1080` | Universal posts, catalogs, carousels, avatars |
| Portrait | `1080 x 1350` | Cross-platform Facebook, Instagram, and LinkedIn feeds |
| Instagram portrait | `1080 x 1440` | Instagram-first feed content |
| Full-screen vertical | `1080 x 1920` | Stories, Reels, Shorts, TikTok |
| Social landscape | `1200 x 630` | Link previews and Open Graph images |
| Landscape video | `1920 x 1080` | YouTube, events, webinars, traditional video |

For advertising, prepare `1:1`, `4:5`, and `9:16` separately when text, faces, or calls to action make automatic cropping unsafe.

## Platform guide

- **Facebook:** Use `1080 x 1350` for portrait feed posts, `1080 x 1080` for reusable cards, `1200 x 630` for links, and `1080 x 1920` for Stories/Reels. Covers: Page `851 x 315`, Group `1640 x 856`, Event `1920 x 1005`.
- **Instagram:** Prefer `1080 x 1440` for Instagram-first feed work, `1080 x 1350` for cross-platform work, `1080 x 1080` for reusable cards, and `1080 x 1920` for Stories/Reels. Keep avatars square and centered.
- **TikTok:** Use `1080 x 1920` for video, Stories, photo sequences, and most ads. `1080 x 1080` and `1920 x 1080` are reusable but do not fill a phone screen as well.
- **YouTube:** Use `1920 x 1080` for Full HD video, `3840 x 2160` for 4K, `1080 x 1920` for Shorts, and `1080 x 1080` for Community posts. Banner: `2560 x 1440` with an approximate safe area of `1544 x 423`.
- **X:** Use `1600 x 900` for landscape, `1200 x 1600` for tall images, `1200 x 1200` for square posts, and `1200 x 628` for link cards. Header: `1500 x 500`.
- **LinkedIn:** Prefer `1080 x 1350` for feed content, `1080 x 1080` for reusable cards, and `1200 x 627` for links. Personal cover: `1584 x 396`; company cover: `4200 x 700`.

## Shared rules

- Use `3:4` for Instagram-first feeds, `4:5` for cross-platform portraits, `1:1` for universal cards, `9:16` for full-screen content, `1.91:1` for link previews, and `16:9` for traditional video.
- Keep every carousel slide at the same dimensions and aspect ratio.
- In `1080 x 1920` designs, keep critical content out of roughly the top `250` px and bottom `350` px.
- Center logos and faces in avatars. Use separate banner templates; extreme ratios should not be cropped from feed artwork.
- Reuse one content system with export presets unless the crop changes reading order, hierarchy, or safe area.
