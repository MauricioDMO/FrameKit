# Hero

Reusable editorial block for a brand message with an eyebrow, title, and description.

## Inputs

- `eyebrow`: short uppercase label.
- `title`: main headline; Markdown is supported.
- `description`: supporting copy; Markdown lists are supported.
- `accentColor`: color for the eyebrow and rule.

## Use when

Use this block when the message needs a clear reading path from label to headline to supporting copy. Keep the surrounding layout, dimensions, and calls to action in the consuming template.

## Constraints

The component is channel-neutral and does not own a background, export size, platform label, or CTA.
