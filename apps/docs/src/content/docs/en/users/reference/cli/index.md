FrameKit publishes two command-line tools:

- [`framekit`](/en/users/reference/cli/framekit) operates on the current consumer project.
- [`create-framekit`](/en/users/reference/cli/create-framekit) creates a project from the canonical starter or updates its official skills.

For the normal setup flow, see [create a project](/en/users/getting-started/create-project). For the package entrypoints used by an integrated project, see the [package API reference](/en/users/reference/package-api).
