Use these pages when bringing a project to the current FrameKit contract:

- [Current contract migration](/en/users/migrations/next) — a checklist for templates, generated output, persistence, access, and server-side export.
- [v0.8 migration record](/en/users/migrations/v08) — a historical record of the 0.7-to-0.8 release path.

The current package manifest reports version `0.8.1`. The current-contract page does not select a release version; it describes actions against the APIs, generated files, storage, and runtime behavior implemented in this repository.
