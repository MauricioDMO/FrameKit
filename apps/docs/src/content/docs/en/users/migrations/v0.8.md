> **Historical record:** This page preserves the documented 0.7-to-0.8 migration context. It is not the current setup guide and does not select an installation version.

The v0.8 release path established the template, generated-registry, Studio, and project-structure conventions that the current documentation now describes as the canonical contract. The historical checklist covered updating the runtime package, reinstalling dependencies, regenerating project output, validating templates, and building the project.

For work on a project today, use the [current contract migration checklist](/en/users/migrations/next), then verify the result with the current [template reference](/en/users/reference/template), [generated-files reference](/en/users/reference/generated-files), and [project structure guide](/en/users/getting-started/project-structure).
