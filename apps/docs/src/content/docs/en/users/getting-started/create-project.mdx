Use the official creator when you are starting a new application.

## Prerequisites

- Node.js `>=22.13.0`.
- pnpm `>=11.14.0` when using pnpm.
- A destination directory that does not already exist.

## Create and run the project

<Steps>

1. **Create the application.**

   <Tabs syncKey="package-manager">
     <TabItem label="pnpm">

   ```bash
   pnpm dlx @mauriciodmo/create-framekit my-project
   ```

     </TabItem>
     <TabItem label="npm">

   ```bash
   npx @mauriciodmo/create-framekit my-project
   ```

     </TabItem>
   </Tabs>

2. **Enter the project and start development.**

   <Tabs syncKey="package-manager">
     <TabItem label="pnpm">

   ```bash
   cd my-project
   pnpm dev
   ```

     </TabItem>
     <TabItem label="npm">

   ```bash
   cd my-project
   npm run dev
   ```

     </TabItem>
   </Tabs>

3. **Open Studio.**

   Visit `http://localhost:3000`. New projects use open mode by default: the
   application redirects to `/editor`, and `/editor` and `/brand` work without
   login. `/login` redirects to `/editor`. To enable login and protected access,
   set `FRAMEKIT_AUTH_ENABLED=true`; only in that mode set
   `FRAMEKIT_ADMIN_PASSWORD` before the first login. `FRAMEKIT_ADMIN_USERNAME`
   is optional and defaults to `admin`.

4. **Create your first template.**

   Continue with [Create your first template](/en/users/getting-started/first-template).

</Steps>

## Creator options

The creator can install dependencies, run pnpm build-script approval, initialize Git, accept or reject prompts non-interactively, and refresh public FrameKit skills. Those switches are reference material rather than required setup steps.

See the [`create-framekit` CLI reference](/en/users/reference/cli/create-framekit) for prompts, `-y`, `-n`, `update-skills`, and recovery when installation is skipped or fails.

:::tip
If PNG rendering reports that Chromium is unavailable, follow the browser installation guidance in [Deployment](/en/users/deployment) or [rendering troubleshooting](/en/users/troubleshooting/rendering).
:::

:::caution
Before exposing a production project to an untrusted network, explicitly set
`FRAMEKIT_AUTH_ENABLED=true`. The value must be exactly `true` or `false` when
present; `NODE_ENV`, credentials, and SQLite do not enable authentication.
:::
