FrameKit turns React templates into editable image workflows. Start with the task you need to complete; the sidebar contains the deeper concepts and reference material.

:::caution
Authentication is opt-in. When `FRAMEKIT_AUTH_ENABLED` is missing or `false`,
`/editor` and `/brand` are open, `/login` redirects to `/editor`, `/settings`
and the access API are absent, and image rendering needs no credential while
retaining its renderer defenses. Set `FRAMEKIT_AUTH_ENABLED=true` before
exposing production to an untrusted network.
:::
