# Using FrameKit

This section is for people who use FrameKit to create and ship template-based image editing experiences. It focuses on the path from choosing a template to working with the visual Studio, CLI, and generated application code.

## Start here

- [Getting started](/en/users/getting-started) - choose a setup path and check the requirements.
- [Create a project](/en/users/getting-started/create-project) - scaffold a new Next.js project with the official creator.
- [Integrate an existing project](/en/users/getting-started/existing-project) - add FrameKit to an existing Next.js application.
- [Understand the project structure](/en/users/getting-started/project-structure) - identify maintained files, routes, aliases, and generated output.
- [Create your first template](/en/users/getting-started/first-template) - add a valid template and open it in Studio.

## Continue with templates and brands

- [Template concepts](/en/users/concepts/templates) - understand template definitions, fields, assets, variants, and rendering.
- [Brand components](/en/users/concepts/brand-components) - understand reusable components and their discovery contract.
- [Create a template](/en/users/guides/create-template) - build and validate a complete template definition.
- [Create a brand component](/en/users/guides/create-brand-components) - add a reusable component, preview, and catalog entry.
- [Template reference](/en/users/reference/template) - check the complete template and validation contract.
- [Brand catalog reference](/en/users/reference/brand-catalog) - check discovery, generated modules, and loaders.

## What belongs here

The user documentation will explain the concepts and workflows needed to:

- choose and customize templates;
- work in the visual Studio;
- use the CLI to generate or manage a project; and
- integrate generated code into React or Next.js applications.

Start here when your goal is to use FrameKit in an application rather than change FrameKit itself. The detailed authoring, Studio, API, deployment, and troubleshooting references will build on this setup path.
