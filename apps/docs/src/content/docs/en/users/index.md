# Using FrameKit

This section is for people who use FrameKit to create and ship template-based image editing experiences. It focuses on the path from choosing a template to working with the visual Studio, CLI, and generated application code.

## What belongs here

The user documentation will explain the concepts and workflows needed to:

- choose and customize templates;
- work in the visual Studio;
- use the CLI to generate or manage a project; and
- integrate generated code into React or Next.js applications.

Start here when your goal is to use FrameKit in an application rather than change FrameKit itself.
