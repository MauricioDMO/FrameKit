# Primeros pasos para colaboradores

Usa este recorrido cuando partas de un checkout limpio de FrameKit. Cubre los requisitos previos del repositorio y la primera ejecución de desarrollo local antes de las guías de arquitectura y flujo de trabajo.

## Empieza aquí

1. Comprueba los [requisitos previos](/es/contributors/getting-started/prerequisites), incluidas las versiones exactas de Node.js y pnpm requeridas por el contrato raíz.
2. Sigue [desarrollo local](/es/contributors/getting-started/local-development) para instalar las dependencias, iniciar Studio y elegir comandos enfocados del workspace.
3. Lee la [guía de arquitectura](/es/contributors/architecture) antes de cambiar código para tener claros los límites del workspace y de la salida generada.
4. Continúa con [desarrollo](/es/contributors/development) para consultar las reglas de implementación. Usa [desarrollo local](/es/contributors/getting-started/local-development) para los comandos enfocados del workspace, o [arquitectura de paquetes](/es/contributors/architecture/packages) cuando un cambio afecte a un paquete público.

## Mantén separados los públicos

Si estás configurando una aplicación de FrameKit generada en lugar de contribuir a este repositorio, usa [primeros pasos para usuarios](/es/users/getting-started). El recorrido para colaboradores no sustituye la configuración del consumidor ni las referencias de la API.
