FrameKit publica dos herramientas de línea de comandos:

- [`framekit`](/es/users/reference/cli/framekit) opera en el proyecto consumidor actual.
- [`create-framekit`](/es/users/reference/cli/create-framekit) crea un proyecto a partir de la plantilla canónica o actualiza las skills oficiales de un proyecto existente.

Para el flujo normal de configuración, consulta [crear un proyecto](/es/users/getting-started/create-project). Para los puntos de entrada del paquete utilizados por un proyecto integrado, consulta la [referencia de la API del paquete](/es/users/reference/package-api).
