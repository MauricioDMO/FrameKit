# Usar FrameKit

Esta sección está dirigida a quienes usan FrameKit para crear y publicar experiencias de edición de imágenes basadas en plantillas. Explica el recorrido desde la elección de una plantilla hasta el trabajo con Studio, la CLI y el código generado de la aplicación.

## Qué encontrarás aquí

La documentación para usuarios explicará los conceptos y flujos necesarios para:

- elegir y personalizar plantillas;
- trabajar en Studio;
- usar la CLI para generar o gestionar un proyecto; y
- integrar el código generado en aplicaciones React o Next.js.

Empieza aquí cuando tu objetivo sea usar FrameKit en una aplicación, no modificar FrameKit.
