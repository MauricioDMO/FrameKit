FrameKit convierte plantillas React en flujos editables para crear imágenes. Empieza por la tarea que necesitas completar; la barra lateral contiene los conceptos y la referencia más detallados.

:::caution
La autenticación es opcional. Cuando `FRAMEKIT_AUTH_ENABLED` falta o es
`false`, `/editor` y `/brand` están abiertos, `/login` redirige a `/editor`,
`/settings` y la API de acceso no existen, y el renderizado de imágenes no
necesita credenciales, pero conserva sus defensas. Define
`FRAMEKIT_AUTH_ENABLED=true` antes de exponer producción a una red no confiable.
:::
