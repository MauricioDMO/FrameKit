## Primeras comprobaciones

Desde la raíz del proyecto, ejecuta el comando que corresponda al síntoma:

```bash
pnpm framekit check
pnpm framekit generate
```

`check` valida las definiciones de plantillas y el contenido resuelto. `generate` actualiza los módulos generados y los recursos de plantilla copiados. Corrige el código fuente mantenido bajo `src/templates/` o `src/brand/` y vuelve a ejecutar el comando; no edites la salida generada.

Para instrucciones de configuración, consulta [Crear un proyecto](/es/users/getting-started/create-project), [Estructura del proyecto](/es/users/getting-started/project-structure) y [Usar Studio](/es/users/guides/use-studio).
