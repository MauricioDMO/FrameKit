## Requisitos

- Node.js `>=22.13.0`.
- pnpm `>=11.14.0` cuando uses pnpm.
- Las aplicaciones existentes deben usar Next.js `>=16 <17`, React `>=19 <20` y React DOM `>=19 <20`.

## El flujo de trabajo

<Steps>

1. **Configura la aplicación.** Crea un proyecto nuevo o integra uno existente.
2. **Añade plantillas en `src/templates/`.**
3. **Genera y valida el registro.** FrameKit escribe los clientes generados y el registro de plantillas.
4. **Abre Studio.** Usa la aplicación generada para editar y exportar tus plantillas.

</Steps>

:::caution
No edites manualmente `src/generated/framekit/`, `public/framekit/` ni `.framekit/`. Son salidas generadas. Mantén `.framekit-data/` en almacenamiento persistente solo cuando la autenticación esté activada y se use la base de datos SQLite predeterminada.
:::

La autenticación está desactivada de forma predeterminada. Define
`FRAMEKIT_AUTH_ENABLED=true` explícitamente antes de exponer producción a una
red no confiable; el modo abierto no inicializa SQLite ni crea un administrador
anónimo.

Después de configurar el proyecto, revisa [la estructura del proyecto](/es/users/getting-started/project-structure) y crea [tu primera plantilla](/es/users/getting-started/first-template).
