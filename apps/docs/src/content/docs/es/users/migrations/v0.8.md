> **Registro histórico:** Esta página conserva el contexto documentado de la migración de 0.7 a 0.8. No es la guía de configuración actual ni selecciona una versión de instalación.

La ruta de lanzamiento de v0.8 estableció las convenciones de plantillas, registro generado, Studio y estructura del proyecto que la documentación actual ahora describe como el contrato canónico. La lista de comprobación histórica incluía actualizar el paquete de runtime, reinstalar las dependencias, regenerar la salida del proyecto, validar las plantillas y compilar el proyecto.

Para trabajar hoy en un proyecto, usa la [lista de comprobación de migración del contrato actual](/es/users/migrations/next) y, después, verifica el resultado con la [referencia actual de plantillas](/es/users/reference/template), la [referencia de archivos generados](/es/users/reference/generated-files) y la [guía de estructura del proyecto](/es/users/getting-started/project-structure).
