Usa estas páginas al adaptar un proyecto al contrato actual de FrameKit:

- [Migración al contrato actual](/es/users/migrations/next) — una lista de comprobación para plantillas, salida generada, persistencia, acceso y exportación del lado del servidor.
- [Registro de migración de v0.8](/es/users/migrations/v08) — un registro histórico del proceso de lanzamiento de 0.7 a 0.8.

El manifiesto actual del paquete indica la versión `0.8.1`. La página del contrato actual no selecciona una versión de lanzamiento; describe acciones sobre las API, los archivos generados, el almacenamiento y el comportamiento del runtime implementados en este repositorio.
